disable-model-invocation: true

---

Пользователь попросил убрать блок Compact Guard из CLAUDE.md этого проекта.

1. Удали блок:

```
node "${CLAUDE_PLUGIN_ROOT}/scripts/cg-hook.js" cmd:remove-rules
```

Скрипт вырезает только текст между маркерами `<!-- compact-guard:start -->` и `<!-- compact-guard:end -->` и оставляет рядом резервную копию. Остального в файле он не касается.

2. Передай пользователю ответ скрипта: какой файл изменён, где копия. Если блока в файле не было — так и скажи, это не ошибка.

3. Скажи одной фразой, что именно перестанет работать: агент больше не будет получать правила записки из CLAUDE.md проекта. Сам плагин при этом остаётся включённым — Ревизор по-прежнему не даст закончить работу со скрытой ошибкой, а правила агент продолжит получать в начале каждой сессии. Вернуть блок можно командой `/compact-guard:init`.

Если пользователь хотел выключить плагин целиком, а не убрать блок, подскажи `/plugin uninstall compact-guard@compact-guard` и не запускай ничего сам.

Отвечай по-русски.
