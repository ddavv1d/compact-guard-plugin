Пользователь попросил проверить Compact Guard.

1. Запусти проверку:

```
node "${CLAUDE_PLUGIN_ROOT}/scripts/doctor.js"
```

2. Покажи пользователю вывод скрипта как есть — это уже готовая таблица ✅/❌ и одна строка итога. Не переписывай её своими словами и не добавляй собственных выводов о состоянии плагина.

3. Если в выводе есть хотя бы одно ❌, повтори по-русски одно конкретное действие, которое скрипт назвал для каждого ❌, и спроси, помочь ли это сделать. Ничего не исправляй без ответа пользователя.

4. Если скрипт не запустился совсем (например, `node: command not found`), скажи по-русски: Compact Guard работает на Node.js 20 или новее, его нужно установить с https://nodejs.org, после чего повторить `/compact-guard:doctor`. Без Node плагин просто молчит и ничего не ломает.

Отвечай по-русски. Никаких оценок вроде «всё отлично», если в таблице есть ❌.
